# AimoiA Image Studio 状态

更新时间：2026 年 9 月 18 日

## 定位

正式产品。负责多供应商模型发现、文生图、图生图、图片保存和本地历史管理。

## 当前能力

- API 地址规范化、模型获取和模型选择。
- 文生图、图生图、URL/Base64 图片响应和异步任务轮询。
- 本地设置、生成历史、图片读取和删除。
- 已接入 `aimoia-core` 和 `aimoia-providers`。

## 当前进度

- 显示名称、窗口标题、PWA 名称和安装包显示名称已迁移为 AimoiA。
- Image Studio 专属图标已设计完成，并已接入桌面端和 PWA 图标资源。
- 旧 `Krill Image Studio` 数据目录优先、新 AimoiA 目录回退已接入。
- 设置兼容和模型解析已有 Rust 单元测试。
- 图生图管理版支持最多 10 张参考图上传、缩略图排序与单张移除；请求会按上传顺序提交多张参考图，蒙版只作用于第 1 张参考图。
- 正在增加用户端/管理端工作区：用户端固定服务地址和 4 个允许模型，管理端通过隐藏入口与密码解锁后配置供应商。
- 已形成“软件授权 + 预付费生图额度”的商业化方案：运营人员在中转服务后台为每位客户创建独立 Key、充值和限额，客户仅在软件中配置该 Key；商业版隐藏服务地址和中转站信息，实施尚未开始。
